# Command Order

## Root Commands

```bash
npm i -g @nestjs/cli
nest new api --package-manager npm --skip-git
cd api
npm run start:dev
```

```bash
npx create-next-app@latest web --ts --tailwind --eslint --app --src-dir --import-alias "@/*" --use-npm
```

## Backend Commands

```bash
# Validation + config
npm install class-validator class-transformer @nestjs/config @nestjs/mapped-types

# Prisma 7 + SQLite adapter
npm install prisma@7 dotenv --save-dev
npm install @prisma/client@7 @prisma/adapter-better-sqlite3

# Initialize Prisma
npx prisma init --datasource-provider sqlite --output ../src/generated/prisma
```

```bash
# Run the first migration
npx prisma migrate dev --name init
npx prisma generate
```

```bash
# Create the Prisma module
nest g module prisma
nest g service prisma --no-spec
```

```bash
nest g module tasks
nest g controller tasks --no-spec
nest g service tasks --no-spec
```
